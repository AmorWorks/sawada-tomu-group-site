株式会社STG ホームページ制作データです。

2026-07-05にStandard+プラン想定でトップページ構成を再整理しました。既存の経営理念、業務内容、求人、代表あいさつ、問い合わせ導線、会社概要情報はなるべく残し、ファーストビュー、導入、強み、サービス、実績、問い合わせまでの流れをブラッシュアップしています。

## 構成

- `index.html`: トップページ本体。ファーストビュー、経営理念、主要ページへの入口、問い合わせフォーム、MAP
- `services.html`: 業務内容ページ。伐採抜根、草刈り年間管理、剪定、外構工事、足場仮設、防草シート施工を1ページで掲載
- `works.html`: 施工実績ページ。実写真・掲載許可が揃うまで掲載候補として構成
- `recruit.html`: 求人ページ。STGの理念に共感できる志を持つ方向け
- `contact.html`: 旧問い合わせURL用の互換ページ。トップページ下部の問い合わせへ移動
- `company.html`: 会社概要ページ
- `styles.css`: デザイン
- `script.js`: スクロール演出、モバイルメニュー、年表示、問い合わせ控え作成
- `assets/`: ロゴ画像
- `assets/hero-video.mp4`: 以前のヒーロー背景動画案。現在のファーストビューでは未使用
- `assets/generated-hero-arborist.png`: ファーストビュー用の生成仮写真
- `assets/generated-works-garden.png`: 業務内容・施工実績用の生成仮写真
- `assets/generated-recruit-team.png`: 求人用の生成仮写真
- `assets/generated-president-message.png`: 代表あいさつ用の生成仮写真

## 理念画像について

経営理念画像の原本は案件管理フォルダ側に保管しています。公開サイトでは画像をそのまま使わず、文言をテキストとしてデザイン反映しています。
公開用 `assets/` には理念画像を置かず、画像ではなく文字として掲載する方針です。

## 仮ビジュアルについて

参考画像に合わせて、黒基調・現場感・写真の迫力を出すための生成仮写真を追加しています。実際の施工写真、社員写真、代表者写真が届いたら、同じファイル名かHTML側の参照を差し替えます。

生成仮写真は実在のSTG関係者・実績ではありません。公開前に必ず差し替えまたは掲載可否を確認します。

## 公開前に確認すること

- Instagramプロフィール文、LINEリンクの正確性
- メールの掲載可否
- ロゴ画像のWeb掲載許可
- 写真や実績の追加可否
- 施工実績として出せる現場名、写真、説明、掲載許可
- 求人条件を載せるか、理念型メッセージ中心にするか
- 社長あいさつ本文、代表者写真
- 支店情報、主要取引先の掲載可否
- メールフォームの受信先メールアドレス
- MAPの表示位置が正しいか
- 生成仮写真のまま先方確認に出すか、本物の写真へ差し替えるか
