## 仮ビジュアルについて

参考画像に合わせて、黒基調・現場感・写真の迫力を出すための生成仮写真を追加しています。実際の施工写真、社員写真、代表者写真が届いたら、同じファイル名かHTML側の参照を差し替えます。

生成仮写真は実在のSTG関係者・実績ではありません。公開前に必ず差し替えまたは掲載可否を確認します。

## 公開前に確認すること

- Instagramプロフィール文、LINEリンクの正確性
- メールの掲載可否
- ロゴ画像のWeb掲載許可
- 写真や実績の追加可否
- 施工実績として出せる現場名、写真、説明、掲載許可
- 求人条件を載せるか、理念型メッセージ中心にするか
- 社長あいさつ本文、代表者写真
- 支店情報、主要取引先の掲載可否
- メールフォームの受信先メールアドレス
- 生成仮写真のまま先方確認に出すか、本物の写真へ差し替えるか
